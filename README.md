# Life Plan Simulator

FIRE（経済的自立・早期リタイア）の可能性を、ブラウザだけで試算するライフプランシミュレータです。

## できること

- 年齢・資産・収支・運用前提・家族・ライフイベントの入力
- 資産推移グラフと年次表
- FIRE 到達年齢・資産枯渇年齢の表示
- 退職年齢・生活費を変えたシナリオ比較
- 設定の JSON エクスポート／インポート（データは端末内のみ）

## 使い方

```bash
npm install
npm run dev
```

ブラウザで表示された URL を開いてください。

```bash
npm test        # 計算エンジンのテスト
npm run build   # dist/ に静的ファイルを出力
```

## シミュレーションの前提

- 月次で資産を更新し、年次で表示
- 期待リターンは固定年率（既定 5%・月次複利）
- 生活費はインフレ率（既定 2%）で上昇
- FIRE: 資産 ≥ 年間生活費 ÷ 安全取出率（既定 4%）
- 税金・社会保険・公的年金は含みません

詳細は [AGENTS.md](./AGENTS.md) を参照してください。
